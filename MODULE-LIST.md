# Community module-list submission

The catalog source README says to add a module to [the original MagicMirror² wiki list](https://github.com/MagicMirrorOrg/MagicMirror/wiki/3rd-party-modules); its generated catalog updates periodically. Verify the current contribution route before submitting. Publishing a repository does not automatically list it.

Source: [MagicMirrorOrg/MagicMirror-3rd-Party-Modules README](https://github.com/MagicMirrorOrg/MagicMirror-3rd-Party-Modules#how-do-i-get-my-module-presented-in-the-new-list).

Before submission, verify each public URL, install into a clean test mirror, record the result, confirm screenshot and attribution, and check the list for duplicate names. Keep entries in appropriate categories. Do not submit a module that still needs changes to install independently. Screenshots may use clearly labelled synthetic data; never expose private calendar or connection data.
